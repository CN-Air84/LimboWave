# Zen / Focus Mode Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a reversible, distraction-free desktop conversation view without changing messages, model routing, tool execution, or permissions.

**Architecture:** Keep Zen mode as local presentation state on ChatView. MainWindow mirrors that state across the live and preview views and hides/restores navigation without changing splitter sizes or advanced-panel preferences. Existing rows update in place; new, streamed, and paginated rows inherit the mode.

**Tech Stack:** Python, PySide6, pytest-qt; existing theme tokens and rich-text rendering.

---

## Design decisions

- Use a reversible view toggle rather than a second transcript or a new conversation/execution mode. This preserves streaming, attachments, selection, drafts, and audit data.
- A small header button (`纯净模式` / `退出纯净模式`) and Ctrl+Shift+F toggle the view. The header and composer are both covered by the blocking conversation-loading overlay. Escape exits from the workspace without intercepting dialogs/popups.
- Hide sidebar/branch navigation, advanced settings, model/permission/context controls, thought blocks, tool steps, compression dividers, and branch actions. Keep attachment actions, copy, retry, send, stop, error messages, and actual authorization dialogs.
- Keep the existing theme. Center a narrower reading column, add vertical space and slightly larger body text with increased paragraph line height. Restore original rich-text formatting when leaving.
- Replace technical live status with a neutral response-in-progress message, but never hide a run error. Do not open compression reasoning popups while focused.
- Mode lasts for the current window (including conversation/preview changes); no database migration or implicit change of execution settings.
