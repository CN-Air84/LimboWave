# 会话导出 Implementation Plan

**Goal:** 接通会话导出入口，默认导出当前分支的单文件 HTML。
**Architecture:** 复用 ExportPanel 和 ExportService；应用层统一隐私确认，服务层逐分支生成独立文件并拒绝覆盖。保留现有其他工作区修改。
**Tech Stack:** Python / PySide6 / pytest。

1. 补充工具栏入口、当前分支预选、批量导出与文件冲突的回归测试。
2. 工具栏添加“导出会话”；弹窗默认 HTML 和当前分支，校验文件名。
3. 服务层新增多分支导出；每分支独立文件、格式校验、排他写入；应用层所有格式统一确认。
4. 运行导出服务、悬浮窗、工具栏测试与静态检查。
