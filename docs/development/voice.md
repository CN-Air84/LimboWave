# VOICE-01：可选语音交互

## 当前范围

桌面主聊天页支持按住说话、转写校对、按需朗读和立即停止。语音转写（STT）与朗读（TTS）分别启用，默认均关闭。没有常开麦克风、唤醒词、后台监听或自动朗读。转写结果只追加到当前草稿，必须由用户主动发送；不会批准工具操作。

当前语音入口在完整聊天界面。浮动陪伴窗口、草稿历史预览和 Web 端暂不提供语音按钮；进入这些页面会停止主聊天页中的语音操作。

## 配置入口

1. 打开 **设置 → 语音**。
2. 分别配置转写与朗读的服务方式、API 基础地址、模型 ID 和 API 密钥。
3. 外部服务使用 HTTPS，地址填到 API 前缀（例如 `https://speech.example/v1`），不要填具体 `/audio/...` 路径，也不要在 URL 中放密钥、查询参数或账号密码。
4. 模型 ID、音色 ID 与兼容程度以服务实际支持为准。朗读需要返回 WAV 音频；语速可设为 0.5–2.0。
5. 勾选要使用的功能，点击 **保存语音设置**。返回聊天后显示相应按钮。仅填写配置不会发起测试请求或上传任何内容。

密钥输入框不回显已保存内容。地址不变时留空保留原密钥；可显式删除。更换地址或服务方式后不会继承旧密钥，需要重新填写（无鉴权本地服务可留空）。即使语音密钥丢失或资料库不可用，也不会匿名向外部服务上传。

## 使用

- **按住说话**：按住鼠标左键或聚焦按钮后按住空格；松开即结束录音并转写。松开到按钮外也会结束。录音超过 60 秒自动结束并开始转写。
- **校对再发**：转写结果追加到输入框末尾，保留转写期间新输入的文字，不自动发送。
- **朗读**：读取当前聊天中最近一条完整助手回复的展示正文，不包含隐藏推理或工具执行详情。最多 4,000 字符，过长时提示而不悄悄截断。
- **停止 / Esc**：取消录音、转写请求、语音生成或播放。开始新录音也会停止原来的朗读。
- **边界处理**：切换会话/页面、替换草稿、开始编辑其他消息、发送、退出、资料库不可用都会使待处理结果失效。录音时失去按键焦点或应用失活会取消采集。
- 语音失败只显示语音状态，不影响文字聊天与原草稿。

## 数据与安全

- 普通设置单独保存在资料目录的 `voice.json`，不进入模型路由配置或 Web DTO。
- 密钥经既有 `CredentialService` 存入加密资料库；配置只保存 `voice.*` 引用。不复用聊天模型密钥。
- API 请求由桌面进程直接发起；不跟随重定向，不继承环境代理，没有云端自动回退。请求、音频和密钥不写入聊天请求日志。
- 应用不主动将原始录音和朗读音频写入磁盘；停止后释放音频缓冲。这里不承诺操作系统交换文件、音频驱动或第三方提供方的留存策略。
- 上传前明确告知录音发往转写服务、回复文本发往朗读服务。语音是 AI 生成，不是假装真人。
- 请求有连接/读写超时和 90 秒总时限。原始录音与合成响应最多 24 MiB，转写响应最多 64 KiB；无效返回和服务端错误仅显示清理后的提示。
- 全量数据重置会清理 `voice.json` 及其临时文件；密钥随既有加密密钥库一起处理。

## 本地部署接口

**现在可用的是自托管兼容服务，而非内置本地模型。** 选择“本地服务 · 兼容 API”，填写 `http://127.0.0.1:8000/v1` 等本机地址。本地模式仅允许 `localhost`、`127.0.0.1` 或 `::1`，可以不填密钥，不会在连接失败时切换云端。服务自身是否联网、是否留存数据由部署者负责。

转写协议：

- `POST {base_url}/audio/transcriptions`
- Multipart：`file` 为 `recording.wav`（16-bit PCM WAV），`model` 为模型 ID，`response_format=json`。
- JSON 返回：`{"text": "转写文字"}`。

朗读协议：

- `POST {base_url}/audio/speech`
- JSON：`model`、`input`、`voice`、`speed`、`response_format: "wav"`。
- 返回完整 RIFF/WAVE 音频字节。

有密钥时发送 `Authorization: Bearer ...`，无密钥本地服务不添加认证头。两个功能可以分别使用不同端点与模型。

### 后续原生引擎

`src/limbowave/domain/voice.py` 的 `VoiceProvider` 是异步协议，只暴露 `transcribe` 与 `synthesize`；未来本地 Whisper 或系统语音适配器可实现该协议，在桌面组装入口注入 `VoiceController(provider=...)`。UI 的录音、校对、停止和草稿边界不需要重做。

未来接入原生引擎时还需增加 provider 类型、模型安装/加载生命周期、取消与线程卸载策略。当前未实现自动下载、模型管理或运行时 native provider 选择，不应把它描述为“已内置 Whisper”。
