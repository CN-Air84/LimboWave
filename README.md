# LimboWave · 灵波


LimboWave 是一款 **Windows 优先的原生桌面 AI 对话与陪伴应用**。它把你选择的模型、愿意留下的记忆，以及日常里那些零碎的话，放在同一个可以长久使用的空间里。

你可以认真讨论一个问题，也可以只说一句“今天有点累”。不必每次开口都带着任务，不必把每段心情都整理成一份需求。

## 有些时候，你需要的不是另一个工作台

电脑上已经有很多催你快一点的软件了。

灵波想留下一扇不同的窗口：不急着替你总结人生，也不要求每一次对话都产出点什么。写作时跑偏的一点灵感、深夜没说完的碎碎念、想留给明天的一个约定，都可以从这里开始。

### 手里的事还没做完，但想说两句话

把灵波切到 **迷你陪伴**，留一个可以拖动、缩放的小窗口。写代码、读东西、等一项任务结束时，不用来回切换整个工作台，也能发一句话、看几句回复。

说完按 **Esc** 收成迷你条；需要展开聊，再回到主界面。两边共用草稿、附件和当前对话，不必复制粘贴，也不会重新开一场聊天。

### 今天不想看参数，只想把话说完

点一下右上角胶囊的书页，进入 **倾诉模式**。侧栏、模型设置、思考过程和工具步骤暂时退后，给文字留出更舒展的阅读空间。

不是关掉能力，而是把复杂的东西先收起来。正在生成的回复、草稿和阅读位置仍在；需要你确认的操作，也不会因为界面变安静就被略过。

### 不想每次见面，都从自我介绍开始

把重要的事情留进记忆：喜欢怎样被称呼，最近在忙什么，哪些建议并不适合自己。

也可以回头改口：“这一条已经不适用了。”灵波提供的不是一份不许反驳的用户画像，而是一套 **看得见、能修改、能整理的记忆**。

## 核心功能

### 🔌 MCP：按需连接外部工具

在「设置 → MCP 服务器」管理本地 stdio 或远程 Streamable HTTP 服务器，启用后可在对话中发现并调用工具。配置即时生效，启动不自动连接；完全访问遵循统一放行规则，其余模式保留权限边界。支持后台连接测试、环境变量凭据引用、参数校验与有界输出，失败不自动重试。详见 [MCP 使用说明](docs/mcp.md)。


### 🪟 两种陪伴视图，让窗口适应你

- **迷你陪伴**：独立原生小窗，显示最近三条消息预览；支持拖动、缩放、可选置顶与半透明，也能选择附件、粘贴图片或拖入文件。
- **全局呼出**：Windows 下首次进入迷你模式时，尝试注册 **Ctrl+Alt+Space**；可以修改或关闭，遇到快捷键冲突会提示，不抢占其他程序的绑定。
- **倾诉模式 / 纯净模式**：在完整聊天界面里收起技术细节，保留发送、停止、复制、错误提示和权限确认。想继续认真做事，随时切回。

它们是同一场对话的不同视图，不是两套彼此断开的聊天记录。

### 🧠 主权记忆：你可以纠正它对你的理解

记忆不该只是后台悄悄发生的一件事。

- **全局记忆与会话记忆分开**：长期偏好可以跨会话使用；眼前这场对话的事情留在当前分支。
- **同一条全局记忆，也能因对话而异**：可以只在某个会话里修改或停用继承的条目，不影响其他会话；以后也能恢复继承。
- **模型提出修改，你看过再决定**：更新正式记忆、归档或删除当前分支记忆，都逐次展示原文和新内容或操作结果，请你确认。更新全局记忆时会明确提醒影响范围。
- **新增策略可选**：模型添加会话记忆默认询问，也可以由你改成自动允许；这不会连带放开已有记忆的更新、归档和删除。
- **重要的事可以升格，过时的事可以归档**：你能手动新增、编辑、删除，把会话记忆升格为全局记忆，或恢复已归档的会话记忆。
- **分支有自己的来路**：从旧消息继续另一种说法时，新分支继承相应历史位置的会话记忆快照，不把后来的变化硬塞回过去。

应用还自带可编辑、可删除的 **「忠实的阅读者」** 预设：鼓励先阅读和回应，而不是急着诊断与修理；坦然承认 AI 身份，不靠编造人类经历制造亲近感。它是一份可调整的交流约定，不是模型永不出错的保证。

### 📝 透明便签与足迹：记下来的东西，不藏起来

**透明便签** 留给近期计划、简短事实和待确认的小事，与正式记忆分开。模型可以整理它，你也能在记忆面板里查看、编辑或清空；它按分支隔离，不是用户看不到的秘密笔记。

**足迹 · 记忆时间线** 则把当前保留的记忆铺成一座小画廊：

- 按日期回看，搜索正文与来源对话，按全局 / 会话、来源和月份筛选。
- 展开完整内容，选择、复制；来源仍可用时，可以回到关联的对话或消息。
- 浏览和筛选不需要请求模型，也不会为了看一眼自己的记忆再消耗一次调用。

正式记忆支持主动关键词检索；经相应授权，模型也可以查找其他会话中的可见聊天正文。**保存下来的记忆与原始聊天记录各有用途，不假装每句话都被永久记住。**

### ⏰ 真的能到点提醒，而不只是在聊天里答应

你可以说：“两小时后提醒我看看进度。”在工具权限允许、提醒创建成功后，这件事会被存成一条真实的 **本地提醒**。

- 到期后写入原会话；模型离线或未配置时，已经创建的提醒仍由应用调度。
- 支持一次性、每天、周一至周五和每周提醒，例如「工作日 12:30 提醒我午休」「每天 23:00 提醒我准备休息」；周期与时区需明确确认。
- 支持查询、取消，以及重新运行并解锁后的延迟补发；周期提醒错过多次只补一次，取消即停止整个周期。
- 点击 Windows 气泡或提醒卡片的 **「回到当初的约定」**，定位到设定时的上下文，继续聊；不打断正在生成的回复。
- 可独立开关轻柔提示音和 Windows 通知气泡；系统气泡不显示提醒正文或会话标题。
- 到点投递不自动调用模型，也不会顺手替你执行命令。

**需要应用保持运行、资料库已解锁。** 退出、关机或休眠期间不能准点推送，不会唤醒电脑；恢复可运行状态后补发。「工作日」目前按周一至周五计算，不自动识别节假日或调休。

### 🍃 低压在场：一点问候，不变成新的消息负担

如果你愿意，可以在设置中开启 **低压在场**：在合适的应用内空闲时机，或你设定的夜间时刻，显示一句安静问候或静态在场标记。

它 **默认关闭**，没有未读计数，不要求回复，可以一键静音；不会为问候调用模型，也不会监听其他软件里的键盘输入。忙着生成、输入、处理权限确认，或窗口不在前台时，都保持安静。

这是可选的轻量问候，与明确设置的定时提醒分开。关掉问候，不会取消你设好的约定。

### 🔧 想做点正事时，也不必换一个应用

陪伴不意味着只能闲聊。需要时，灵波也提供有权限边界的 Agent 工具：

- **文件与工作区**：读取文件、列目录、搜索文本、创建文件、精确修改内容。
- **终端执行**：在授权范围内运行当前平台的 Shell 命令，查看输出、退出码和超时状态。
- **日常环境信息**：按你提供或确认的地点，联网查询天气、日出日落与当地时间；不通过 IP 或设备语言猜测你在哪里。
- **过程可见**：需要时展开模型提供的思考内容、工具步骤和运行状态，也可以停止生成。

权限提供 **仅聊天 / 自由读取 / 完全访问 / 自定义** 档位，并区分目录、域名等资源范围。不想让 AI 动电脑，就留在仅聊天；需要工具，再按实际用途开放。“完全访问”代表你预先授权所有本地工具操作：文件可超出工作区，网络可访问内网、Fake-IP 和非标准端口，记忆变更不再弹窗；工具调用不受话题禁区拦截。其他档位仍保留原有边界。请仅在信任当前模型与会话时开启。

> **受控联网（NET-01）**：设置 → 联网搜索可配置 Google / Bing（经第三方 SerpAPI）、Tavily、Azure Bing 旧资源兼容或自定义 JSON API；搜索默认关闭，需要对应服务的 API Key，密钥仅保存到加密资料库。只读网页抓取不需要搜索 Key，但仍需联网授权。搜索摘要和网页正文会明确区分，并附来源 URL、查阅时间与截断标记；失败时如实报告，不伪称已阅。详见 [联网配置与安全边界](docs/development/network-access.md)。

### 🎛️ 模型可以换，对话不必跟着搬家

- **多站点、多模型**：支持配置 OpenAI Chat Completions / Responses、Anthropic Messages、Google Generative AI 协议端点，也可接入符合相应协议的本地服务。
- **自己选模型**：填写端点、密钥并添加实际模型；可检测流式、思考、工具等能力，再设置默认聊天模型。
- **逻辑模型管理**：把一个逻辑模型绑定到不同站点的实际模型，管理首选站点和绑定顺序，不必把服务商地址记成日常使用的一部分。
- **切换由你掌握**：端点失败时不会静默跨站点重发，避免对话在你不知情的情况下换一个去处。

你可以在不同会话里使用不同模型，保留各自的交流上下文与记忆定制。具体的回答风格、图像理解和工具调用能力取决于所选模型及服务端支持。

### 翻篇，不必删除过去

在 **会话记忆 → 翻篇与禁区**，可以另开“不带入过去”的聊天，保留原记录但不注入全局个人记忆或旧聊天；也可以保存全局话题禁区，按话题、别名及明确资料 ID 阻止未来自动复用。

这是应用层过滤，不是仅提示模型“别提了”。缺少来源的旧记忆、助手回复、便签和摘要采用保守停用策略，不承诺识别所有同义表达，也不等同物理删除。[完整边界与备份恢复说明](docs/PRIVACY-BOUNDARIES.md)。

### 📱 离开桌前，也能接着聊

可选的 **局域网 Web 访问**，让同一网络中的可信手机或其他设备配对后访问资料库、继续对话。它默认关闭，需要桌面应用运行并保持解锁；配对设备通过密码核验后可访问当前资料库的全部会话，不是仅分享某一场聊天。

Web 端不开放模型工具执行或工具审批，也不能远程解锁电脑上的资料库。它是另一种聊天入口，不是把桌面控制权一起交出去。

想长期放在自己的服务器上运行，也有独立的 **LimbowaveOnServer** 部署路线；请按部署手册检查对应分支、认证和 HTTPS 配置，不要直接把桌面局域网端口暴露到公网。

## 原生桌面，不再给聊天框套一层浏览器

**桌面界面使用 Python + Qt 6（PySide6），不是 Electron，也不依赖嵌入式浏览器来显示聊天。**

为了几段文字、一个输入框和一扇陪伴窗口，我们选择直接做桌面程序，而不是再请一整个 Chromium 来当客厅。小窗口、快捷键、文字选择和界面切换，都在 Qt 桌面界面里完成。

这里说的“原生”是 GUI 路线：具体使用的是 **PySide6，而不是 PyQt**；模型运行仍依赖 **Pi / Node.js**，可选的手机 Web 界面也有自己的前端。它不是“完全没有 JavaScript”，更不是凭技术栈就能保证的“零占用”。

我们在意常驻桌面时的负担，但没有可复现的对照测试前，不用“几十 MB”“比同类快几倍”来替代实际体验。

## 数据留在哪里，也应该说清楚

- **本地资料库**：消息正文、记忆内容和 API 密钥使用资料库密钥加密保存；主密码用于解锁。这里指敏感内容加密，不代表所有数据库元数据都加密。
- **使用模型时仍会发送内容**：你发送的对话、相关记忆和附件可能随请求交给所选模型服务；天气等联网工具也会访问对应服务。本地保存不等于全程离线，也不等于内容永不离开设备。
- **导出与备份不同**：HTML 导出是明文，分享前请检查内容；`.lwb` 备份使用独立密码加密，请妥善保管密码。
- **整理不等于抹除全部历史**：删除当前记忆条目，不会同时抹去旧分支的历史快照；删除整个会话会清理其所属数据，但已升格的全局记忆副本仍需单独管理。

灵波希望提供的安心，来自你能看见和控制这些行为，而不是一句没有边界的“绝对安全”。

## 开始使用

**当前仍在持续迭代，以下介绍以仓库源码为准，不代表旧安装包已经包含全部功能。** 桌面以 Windows 为优先平台；Linux 已有初步支持，具体环境与限制见 [Linux 使用说明](docs/development/linux.md)。

### 从源码运行桌面版

准备 **uv、Python 3.12–3.13、Node.js ≥ 22.19.0 与 npm**。Python 依赖由 uv 管理；模型运行需要 Pi。进入项目根目录后执行：

```powershell
uv sync --locked
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.86.0
uv run python -m limbowave
```

首次使用时：

1. 创建本地资料库并设置主密码；以后用它解锁自己的数据。
2. 在引导中填写模型服务的地址与密钥，拉取或手动添加实际模型。
3. 明确选择默认聊天模型，然后开始第一场对话。

**需要自行准备可用的模型服务；本项目不附送模型额度。** 接入本地兼容服务时，也需要自行启动和配置该服务。只运行桌面界面不需要额外启动 Web 前端开发服务器；启用手机访问前，请按局域网文档准备 Web 构建产物。

如需自行打包 Windows 程序，见 [打包说明](docs/development/packaging.md)；Linux 请使用其专用启动流程，避免覆盖共享目录中的 Windows 环境。

### 几个常用入口

| 想做什么 | 入口 |
| --- | --- |
| 进入 / 返回迷你陪伴 | 对话区右上角胶囊左侧气泡，或应用内 **Ctrl+Shift+M** |
| 在其他应用中呼出迷你窗口 | Windows 下进入过迷你模式后，默认 **Ctrl+Alt+Space** |
| 在迷你窗口发送 / 换行 | **Ctrl+Enter** / **Enter** |
| 收起迷你窗口 | **Esc**，收成迷你条，不退出程序 |
| 切换倾诉模式 | 对话区右上角胶囊右侧书页，或 **Ctrl+Shift+F**；在对话中按 **Esc** 恢复完整界面 |
| 管理全局 / 当前会话记忆 | **设置 → 记忆** / **会话工具栏 → 记忆** |
