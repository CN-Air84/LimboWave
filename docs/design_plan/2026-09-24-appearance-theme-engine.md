# LimboWave 完整外观主题引擎实施计划

> 日期：2026-09-24

## 依据

以 `G:/YuanyueTTS/docs/plans/2026-07-26-appearance-theme-system-design.md`、对应 implementation plan、review response 与 manual test 为产品参考；仅复用需求和性能边界，代码按 LimboWave 的 PySide6、偏好服务和三栏主窗口重新设计。

## 配置面

- 保留 LimboWave 深色主题，并提供清昼、晨雾蓝、青竹、琥珀纸、绯樱、薰衣草雾、海盐青预设。
- 自定义主题：从当前另存、显式保存、重命名、删除；预设只读。
- 九个颜色：窗口、卡片、组件、强调、正文、信息、警告、错误、页签指示。
- 背景：托管图片、cover/contain/stretch/tile、九宫格位置、图片透明度、遮罩色、遮罩透明度。
- 效果：内容开关/透明度/模糊半径、卡片开关、控件总开关、按钮/输入/选择/列表表格/滚动条五类、左栏独立开关/透明度/半径、页签指示透明度。
- 文字光晕：开关、最小/最大强度、最小/最大半径，按字号插值。
- 悬停停用：开关、进入/恢复时长。
- 字体：系统字体、导入字体、字号缩放。

## 架构

1. 新建不可变主题值对象与原子 `theme-state.json` 仓储；内置主题不写盘，自定义主题和 active id 单文件提交。
2. 图片导入到数据目录 `themes/assets/`，校验大小/像素/格式后按内容哈希命名。
3. 背景引擎使用工作区共享的有界缓存，支持两套独立模糊半径和完整背景合成参数；控件绘制仅取 source rect。
4. 主题令牌由完整颜色模型派生，外观改动即时预览；保存语义在主题服务中，不再把所有字段平铺进 preferences。
5. 设置页按主题、颜色、背景、材质、控件、光晕、字体分区，并给每个字段回归测试。

## 验收

- 同一背景参数和半径复用缓存；消息滚动和 hover 不增加合成次数。
- 预设只读，自定义 CRUD 重启可恢复；损坏状态回退但不覆盖原文件。
- cover/contain/stretch/tile 和九宫格有结构/像素测试。
- 内容与左栏半径/透明度独立；五类开关保留各自状态。
- 字体和背景非法输入安全回退。
- Ruff、mypy、相关 UI/unit 测试通过；全量测试中只报告与本功能无关的既有失败。
