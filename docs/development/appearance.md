# 外观主题引擎

> 更新日期：2026-09-29

LimboWave 的外观系统以 `theme-state.json` 为主题唯一事实源，字体/字号等机器级偏好继续存放在 `preferences.json`。需求边界参考 `G:/YuanyueTTS/docs/plans/2026-07-26-appearance-theme-system-design.md`，实现使用 LimboWave 自己的 PySide6 组件和三栏工作区，没有移植老项目的 PyQt5 主题代码。

## 设置项

外观页不使用纵向卡片堆叠。顶部固定一条横向二级选项卡栏，分为 `主题 / 颜色 / 背景 / 材质 / 控件 / 光晕与交互 / 字体`；下方只呈现当前子页表单，窄窗口时 tab bar 自带滚动按钮。二级栏与一级设置导航共用 `AnimatedPageStack`：指示器以 230 ms `OutCubic` 缓动横移，旧内容 160 ms 向目标方向反向滑出并淡出，新内容 230 ms 从对应方向滑入并淡入；连续点击会取消旧 generation，从当前几何位置重新定向。

### 主题生命周期

内置主题包括 `灵波夜`，以及计划书中的 `清昼`、`晨雾蓝`、`青竹`、`琥珀纸`、`绯樱`、`薰衣草雾`、`海盐青`。内置主题只读，可实时修改为草稿并“另存为”自定义主题。自定义主题支持新建、显式保存、另存为、重命名、删除和放弃修改。

切换主题、离开外观页、返回聊天或关闭主窗口时，未保存草稿会要求保存、放弃或取消。删除当前自定义主题后回退到 `灵波夜`。

### 颜色

每个主题保存九个颜色：

- 窗口底色、卡片底色、组件底色；
- 强调色、正文色、页签指示色；
- 信息色、警告色、错误色。

运行时从这九个颜色派生 hover、pressed、边框、次要文字和代码块令牌，旧视图不需要各自维护一套调色逻辑。

### 背景

- PNG、JPEG、BMP 导入后经 EXIF 转正并规范化为 RGBA PNG；WebP 和动画图片被拒绝。
- 源文件最大 32 MiB，解码后最大 64 MP。
- 资源按像素内容和尺寸哈希托管在 `<data_root>/themes/assets/`，不依赖原文件继续存在。
- 支持填充裁剪、完整适应、拉伸、平铺和九宫格位置。
- 图片透明度、遮罩色和遮罩透明度随主题保存。
- 未引用资源不会自动删除；设置页提供显式扫描、确认和清理入口。

### 材质与控件

- 内容区：独立开关、不透明度、模糊半径。
- 卡片：决定聊天气泡、附件栏等主题卡片是否使用内容区共享材质。
- 控件：总开关保留各分类选择；分类为按钮、文本输入、选择控件、列表/表格、滚动条。
- 主页弹层：模型/思考/站点上拉列表、附件/权限菜单共用“选择控件”材质开关；应用内悬浮窗共用“卡片”开关。均使用内容区的模糊半径和不透明度，保留清晰的文字、边框与选中态。关闭内容区材质、没有可用背景或离开工作区时回退纯色；系统文件对话框不受影响。
- 左侧栏：独立开关、不透明度和模糊半径。
- 页签指示：独立颜色和不透明度。页签的悬浮/选中底色不取调色板的 hover/组件色（派生结果里 hover 比组件色更重），而是正文色叠加（悬浮 6%、选中 12%），保证选中永远比悬浮醒目。
- 悬停停用：可关闭；启用时只把目标控件底板渐变恢复为实体表面，不降低文字和图标的不透明度。进入、恢复时长随主题保存。设置页一级分类按钮自带悬浮/选中底色，不参与悬停停用。

### 文字和字体

文字光晕保存开关、最小/最大强度与最小/最大半径，按实际字号线性插值。当前安全实现只给透明背景的 `QLabel` 暗色字形安装白色 alpha 光晕；近白文字、图片标签、显式 opt-out 和有实体标签背景的控件会跳过，避免把整个控件当成文字阴影。

字体可选系统字体或导入 TTF/OTF/TTC。导入文件最大 16 MiB，按内容哈希复制到 `<data_root>/fonts/`。字体族必须先被 Qt 字体数据库识别，写入 QSS 前还会过滤控制字符和 CSS 特殊字符。字号缩放继续独立保存，并覆盖登录页等启动界面。

## 渲染与性能

`ui/backdrop.py` 的工作线程完成解码、缩放、合成和 Pillow Gaussian blur。GUI 线程只安装 `QPixmap`，三栏和子区域通过同一帧的 source rect 绘制，不为每个控件复制背景图。

- 内容区和左栏的两个半径在一次 generation 中合成。
- 同参数帧进入 192 MiB LRU；消息滚动、hover 和文字更新不触发背景重算。
- resize 延迟 150 ms 合并；相同 pending 请求去重，新 generation 永远不会被旧结果覆盖。
- 最大合成尺寸为 3840×2160；等待新帧时保留旧帧或纯色，不显示空白。
- 主窗口关闭时取消队列并关闭 worker。
- `ui/popup_material.py` 让独立菜单/上拉窗口按全局坐标采样同一张背景帧，越出工作区的部分使用主题实体底色兜底。弹层打开、悬停、滚动和进出场动画不提交新模糊任务、不复制全屏背景、不增加逐帧 QSS 刷新；只复用既有退场截图，悬浮窗销毁时自动解除材质通知连接，复用的列表/菜单不重复注册。磨砂对象是主题背景图，不是桌面或聊天文字的实时截图。

在当前开发机、两套半径 `18/28 px` 的直接 worker 基准中：

| 输入/输出 | 三次耗时 |
| --- | --- |
| 1920×1080 | 163.8 / 168.3 / 164.1 ms |
| 3840×2160 | 659.5 / 641.9 / 685.7 ms |

这是本机工程基线，不是跨机器 SLA。它落在参考计划的 1080p 300 ms、4K 800 ms 目标内；GUI 线程不会执行上述工作。

## 持久化和恢复

`<data_root>/themes/theme-state.json` 同时保存 schema、revision、active theme id 和全部自定义主题，使用同目录临时文件、flush、fsync 与 `os.replace` 原子提交。内置主题只存在于代码。

损坏状态文件会被改名为带 UTC 时间戳的 `theme-state.corrupt-*.json`，随后安全回退到 `灵波夜`，不会用默认内容覆盖损坏证据。上一版 LimboWave 的单背景图/单半径偏好会迁移成托管图片和自定义主题。

## 主要实现文件

- `src/limbowave/domain/appearance.py`：不可变主题值对象、校验、内置主题。
- `src/limbowave/application/services/appearance_theme_service.py`：状态事务、自定义主题 CRUD、资产导入与手动清理。
- `src/limbowave/ui/appearance_editor.py`：完整外观编辑器和草稿交互。
- `src/limbowave/ui/backdrop.py`：异步背景合成、generation 和有界缓存。
- `src/limbowave/ui/theme.py`：设计令牌和分类控件 QSS。
- `src/limbowave/ui/theme_effects.py`：文字光晕和悬停停用。

### 光标 Reveal 高光

- 按钮、输入/选择控件和启用的列表项显示随光标移动的径向高光，并局部照亮边框。使用约 192 个逻辑像素的直径，Qt 自动处理高 DPI。
- 深色表面用低透明度白光，浅色表面用淡主题色；进入 120 ms、离开 180 ms。关闭 Qt 通用 UI 动画时直接显示/隐藏静态高光。
- 高光仅在目标表面或当前列表行内绘制，不替换系统光标，不截获鼠标或键盘输入，与点击波纹共存。没有全窗口刷新定时器，不改写目标控件样式或重算背景模糊。
- 复选框、单选框、禁用控件、列表空白处不参与。单个控件或列表设置 `revealDisabled=True` 可停用，也尊重既有的 `themeEffectDisabled`。
- 滚动、列表数据变化、控件隐藏/移动/缩放和窗口失焦时清理旧位置高光。事件过滤器随窗口释放，不保留窗口的强引用。
- 实现位于 `src/limbowave/ui/cursor_reveal.py`，在启动和主题刷新时通过 `install_cursor_reveal(window)` 幂等安装；后续创建的控件也自动接入。
