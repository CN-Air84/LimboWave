# 工具步骤显隐性能验证

## 实现范围
- 复用 ConversationProcess：工具结果归一化、摘要/详情投影在子进程中执行；GUI 只保留事件顺序、展示状态和 QWidget 操作。
- 工具事件后的消息/结束事件有序排队，按收到事件的时间计算耗时（不把 IPC 延迟计入工具耗时）；收尾/退出等待队列完成，跨 run 的迟到结果丢弃，后端故障不回退到 GUI 做重计算。
- 历史视图的消息解密、工具投影、附件索引、权限及分支元数据也交给该进程；Markdown 和图片显示准备仍由既有后台读取线程承担，Qt 控件留在 GUI。
- 展示字段不落库、不参与审计对象相等判断；完整工具参数不截断。界面参数预览限制 16,000 字符，并明确提示完整参数仍在审计记录中。
- 动画只覆盖视口附近消息；复用可见邻接项之间的间距对象，缓存换行测高，并在内容/宽度变化时失效。保留反向切换、详情展开状态、流式更新、隐藏窗口和关闭动画的回退行为。

## 验证
- 相关后端/历史/UI 回归：**86 passed**（离屏 Qt）。
- Windows 原生 Qt 的显隐/性能回归：**18 passed**。
- Ruff：通过；Mypy：9 个改动源文件通过。
- 真实 spawn 子进程测试覆盖：不同 PID 下格式化、开始/结束/settled 顺序、完整审计保存、历史投影、错误可见、IPC 延迟不影响工具耗时、中断等待审计保存。

## 动画合成基准
60 条消息，每条 6 个工具步骤，重复 6 次显隐；手动推进时间线并处理 Qt 事件，不是实时 FPS 测量。为隔离布局/调度收益，两组都使用当前工具视图缓存实现，只切换原/新 ChatView 动画路径。

| 指标 | 原路径 | 优化后 |
|---|---:|---:|
| 同时动画的消息行 | 60 | 4–7 |
| 切换调用中位耗时 | 12.17 ms | 9.56 ms |
| 帧处理中位耗时 | 8.80 ms | 4.38 ms |
| 帧处理 P95 | 19.94 ms | 7.39 ms |

数据来自本机离屏合成负载，不能直接等同于用户实际场景的帧率。探针和 JSON 结果保存在 .var/tool-step-performance/。

## 全量回归限制
完整 unit + UI 运行记录：2396 passed / 17 failed / 7 skipped / 1 teardown error。其后，3 个由本次抽取异步历史帮助函数引起的回调夹具依赖缺失已修复，对应 6 项回归通过，并纳入最终 86 项相关回归。

其余失败涉及 thinking trial、模型选择回调、登录、复选框、遮罩/主题、诊断和设置列表。只读源码基线对照仍复现复选框、诊断、主题弹层销毁和设置列表问题；部分视觉失败依赖执行顺序。工作区还包含同期修改，thinking trial 的基线接口与当前测试也不完全匹配，因此不宣称全量测试全绿，也不把全部剩余失败武断归为既有问题。未为本次工具步骤优化改动这些功能。
