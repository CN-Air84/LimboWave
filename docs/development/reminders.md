# 一次性会话提醒

模型现在可以创建、查询和取消真实的本地提醒，而不是仅在回复里承诺“到时提醒你”。

## 使用

用户可以直接说：

- “两小时后提醒我看编译结果。”
- “明天晚上八点提醒我喝水。”（模型先确认设备日期、时区；有歧义时询问用户。）
- “这个会话还有哪些提醒？”
- “取消刚才那个喝水提醒。”

默认「自由读取」和「自定义」档位下，创建提醒需用户确认一次；「完全访问」沿用免确认策略。「仅聊天」仍然禁止工具。查询和取消当前会话的提醒无需额外确认。Web 来源仍然禁止执行模型工具，但可以接收已创建提醒的会话消息。

## 工具契约

### `set_reminder`

```json
{"delay_seconds": 7200, "reason": "查看编译结果"}
```

或指定包含时区偏移的绝对时间：

```json
{"target_time": "2026-10-27T20:00:00+08:00", "reason": "喝水"}
```

- `target_time` 与 `delay_seconds` 必须二选一。
- 相对延时使用正整数秒；绝对时间必须包含 UTC 偏移（例如 `+08:00` 或 `Z`）。
- 拒绝无时区、已过去、非有限、溢出和模糊时间；`reason` 为 1–2000 字非空文本。
- 仅成功响应中的 `scheduled: true` 表示已持久化；同时返回 `id`、计划时间、状态、原会话/分支和投递限制说明。
- 所属会话和分支来自应用的活动运行上下文，模型不能指定或伪造。

### `list_reminders`

```json
{"status": "pending", "limit": 20, "offset": 0}
```

`status` 可为 `pending`、`delivered`、`cancelled` 或 `all`，默认 `pending`。按计划时间、ID 排序，只读当前会话；`limit` 为 1–50，`offset` 为 0–10000。读取下一页使用返回的 `next_offset`。达到工具输出字节上限时保留完整条目，标记 `truncated`，仍可继续分页。

### `cancel_reminder`

```json
{"reminder_id": "创建或查询结果中的 id"}
```

只能取消当前会话中未送达的提醒；重复取消幂等，已送达不能撤回。取消与投递通过条件状态更新竞争，最终只能有一个结果。

## 到期行为与边界

- 应用在资料库解锁后启动独立于模型内核的调度任务，通常每秒扫描到期记录；模型离线或未配置时仍可投递既有提醒。
- 到期后写入原会话、原分支的一条“⏰ 系统定时提醒”，必要时标注“延迟补发”。在当前可见的对应会话中追加显示，并触发短暂的任务栏提醒；不会强行切换会话或打断流式生成。
- 消息由应用生成，不消耗模型调用，不自动检查编译结果、执行命令或再次运行 Agent。它只是提醒用户去做约定的事。
- **本版不是操作系统后台服务**：需要应用保持运行、资料库已解锁、设备处于可执行状态。关机、休眠或退出期间无法准点推送，不会唤醒电脑；重新打开并解锁后补发。
- 只支持一次性提醒，不支持重复日程。每个会话最多 100 条待触发提醒；删除原会话或分支会级联清理其提醒。
- 更新源码后需重启应用进程使新工具清单和调度器生效；本次不构建或替换已打包的安装程序。

## 持久化与生命周期

SQLite schema 19 新增 `reminders` 表；旧库增量迁移，原有消息不重写。提醒正文复用资料库密钥加密，计划时间与状态等索引元数据明文保存。检索使用 UTC 时间索引，库内保留原始指定偏移；工具返回的时间和新提醒卡片使用设备本地时区显示，并保留明确的 UTC 偏移。转换只改变显示，不改变触发时刻。历史消息不自动改写。

每次投递在同一事务内完成条件状态转换及会话消息插入；失败回滚，重启后可重试。独立调度实例不会为同一提醒生成重复消息。提醒消息 `run_id=None`，使用 `notice_reminder_…` ID，不伪造模型运行或允许重新生成这类消息。

调度扫描在线程中执行，不阻塞 Qt；退出时取消并等待在途存储工作释放连接，然后关闭资料库。重置和恢复期间不再调度。日志仅记录错误类别，不记录提醒正文。

## 声音与 Windows 通知气泡

在 **设置 → 提醒通知** 中，可以分别开关「播放轻柔提示音」和「显示 Windows 通知气泡」，也可以按「试听提示音」先听效果。两项默认开启，只作用于用户明确设置的定时提醒，不会让普通模型回复或「低压在场」额外发声。

- 提示音是本项目自行合成的 0.72 秒低振幅三音清脆铃声 WAV（C6–E6–G6 依次轻轻上行，每个音保持固定音高、快速圆滑起音，末音稍留余韵，无水滴下滑音），通过延迟初始化的 `QSoundEffect` 播放；不会回退到刺耳的系统默认声音。
- Windows 使用 `Shell_NotifyIconW` 原生气泡，设置 `NIIF_NOSOUND`，避免系统默认声音与轻柔提示音叠加。气泡尊重 Windows 的通知策略，是否实际显示仍由系统决定；提示音由应用开关独立控制。
- 气泡仅显示“提醒已到时间”或提醒数量，**不把提醒正文、会话标题送入 Windows 通知**，以免锁屏/共享屏幕泄露内容。
- 点击气泡会恢复主窗口并定位到相应会话的提醒；通过历史预览打开，不中断正在运行的模型。若有未处理的权限/模态对话框，则先保留它，不强行导航。分组气泡定位到最近一条提醒。
- 同一批到期提醒在 250 毫秒内合并；两次声音/气泡至少间隔 5 秒。静音、数据重置、恢复、退出会清除待播放提示并移除本次运行创建的通知区图标。
- 没有音频设备或 Windows 通知不可用时，持久化的会话提醒仍然保留。系统气泡不是后台推送服务，应用退出/电脑休眠时的限制不变。

音频资源：`src/limbowave/ui/assets/reminder-soft.wav`；可用 `scripts/generate_reminder_sound.py` 确定性重新生成，无外部下载音频和新增 Python 包依赖。既有 PyInstaller 资源收集会包含该 WAV；分发旧版安装包时仍需重新打包。
