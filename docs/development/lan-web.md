# 局域网移动 Web：使用、打包与验收

## 范围与安全前提

局域网访问**默认关闭**，不是独立后台服务。主机上的 LimboWave 必须保持运行、资料库已解锁，手机与主机需要网络互通。退出应用、关闭服务或资料库失效后，手机不能继续使用。不要为方便连接而关闭防火墙、映射路由器公网端口或绕过浏览器证书警告。

配对并通过资料库密码核验后，允许该设备查看**当前资料库的全部会话**，不是只分享当前会话。只配对自己信任的设备。配对状态仅对**本次服务运行有效**：关闭、重启或撤销后旧票据、Cookie 与服务 epoch 不能继续授权，需重新配对。配对邀请也是凭据，不应发到群聊、截图公开或写入日志。

Web 默认禁止**全部工具**，包括看似只读的工具；不是只禁终端、文件写入等高风险工具。手机不能审批工具、修改站点密钥或远程解锁主机资料库。手机需要输入资料库密码用于身份核验，但服务绝不向手机下发数据库主密钥。不要把桌面的工具审批权限自动继承给 Web。

## 开启与关闭

1. 在电脑启动应用并解锁资料库，打开**设置 → 局域网访问**。
2. 选择电脑实际连接手机网络的私有 IPv4 地址与空闲端口（默认 8765）。不要给手机填写 `127.0.0.1`，它指向手机自身；也不要使用 `0.0.0.0` 作为访问地址。
3. 推荐选择 PEM 格式 HTTPS 证书及对应私钥。若不配置二者，须明确勾选“允许无证书 HTTP（我已了解明文聊天及主动篡改风险）”，再点击“开启局域网访问”。以面板显示的实际地址为准。证书无效时不会自动降级；只填一个文件仍拒绝启动。
4. 手机访问面板地址。在电脑生成两分钟配对邀请并扫码；也可输入备用配对码，在电脑核对校验短语后确认。
5. 配对后手机必须核验当前资料库密码（HTTP 和 HTTPS 均要求）。HTTP 页面还须确认风险；通过前无法读取会话、订阅 SSE 或执行命令。
6. 管理面板可查看/撤销设备。关闭服务、服务重启或设备撤销后须重新配对和核验。关闭 Web 不会打断电脑端生成。

只把短期邀请交给可信设备，不在 URL 查询参数传主密码、长期令牌或 API 密钥。手机刷新、重连不代表重新发送；服务重启后必须重新配对，不能自动重放旧命令。

## HTTPS：IP SAN 和手机信任缺一不可

证书必须满足以下两项，单纯“有一个自签名证书”不够：

- 服务器证书的 `subjectAltName` 含 **IPAddress 类型的实际局域网 IP**。只写 Common Name、`localhost`、DNS SAN 或另一块网卡的 IP 都不够。证书和私钥必须匹配，证书在有效期内。
- 手机实际信任签发该证书的 CA/证书链。开发用本地 CA 在电脑受信任，不代表手机也已信任。只通过受控方式向自有手机导入根 CA，**不要复制 CA 私钥或服务器私钥到手机**。

iOS 通常还需在“设置 → 通用 → 关于本机 → 证书信任设置”显式启用相应根证书的完全信任；Android 的证书安装入口与用户 CA 信任行为随系统、浏览器和设备管理策略不同。必须在目标手机浏览器实测，不能仅以安装成功判断。按设备当前系统文档操作；企业管理设备可能禁止安装。

DHCP 导致主机 IP 变化后，更新证书的 IP SAN、重新选择监听地址并重新配对；可考虑路由器 DHCP 地址保留。局域网不自动降级 HTTP。无证书 HTTP 只在用户显式确认后开启，不应在公共 Wi-Fi 或不可信网络中使用。

## 无证书 HTTP 与资料库密码核验

2026-10-06 按用户要求新增 HTTP 可选模式；这覆盖原计划的“LAN 必须 HTTPS”默认限制，不改变认证、工具权限和单运行通道。

- HTTP 不加密聊天内容与 Cookie，网络攻击者可能监听、冒用设备或篡改网页。密码核验不能替代 TLS。
- 密码使用一次性 RSA-OAEP/SHA-256 + AES-GCM 信封，不明文发送。每次挑战绑定配对设备，120 秒失效、只能消费一次。服务不公开资料库 KDF 盐、可复用密码校验值或主密钥。
- **该信封不防主动 HTTP 中间人攻击**：攻击者仍可替换页面/公钥以窃取资料库密码。桌面与手机均显示风险确认。只有可信 HTTPS 才提供网页/服务器身份验证与完整传输保护。
- 密码不保存到浏览器存储或配置，提交后清空；服务只在内存中验证当前 vault 密码包装，匹配已解锁的本机密钥，绝不改变桌面锁库状态。Python/JavaScript 无法承诺完整内存擦除。
- 每设备最多 5 次失败后撤销；服务全局每分钟最多 30 次核验，Argon2 核验串行且在后台线程，不在 Qt 线程执行。过期、撤销和旧挑战均不能获得权限。
- 回环开发 fixture 可省略 gate；生产桌面始终装配 gate，非回环启动入口缺少核验器会拒绝启动。

## 多端和使用边界

桌面与手机共享资料库和运行时，只有一个执行通道。两端同时发送时，一个接受，另一个应收到冲突（409）并保留草稿，不排队重复执行。浏览历史不应改变另一端正在执行的会话；停止必须针对指定 run。响应丢失时先查询命令回执，不盲目重发。断线恢复由快照与事件流协调，离线不自动提交缓存草稿。

本版不承诺公网访问、独立 headless 启动、离线聊天、主机睡眠期间可用、多任务并行或在手机执行/审批主机工具。

## 开发与冻结打包

目录合同：

- 前端源码、清单和锁文件：`G:/LimboWave/web`；提交 `package-lock.json`，不提交 `node_modules`。
- Vite 生产输出：`G:/LimboWave/src/limbowave/web/static`；只放可公开的构建产物，不放密钥、资料库或手工源码。此目录已被 Git 忽略。
- 生产服务直接读取 Python 包旁的 `web/static`，无需额外前端进程；缺少产物不得静默跳转 Vite 开发服务器。

`G:/LimboWave/scripts/packager.py` 的 GUI 和 CLI 共用打包入口。安装项目开发依赖以及符合前端依赖要求的 Node.js/npm 后，每次冻结之前依次执行：

```powershell
npm --prefix G:/LimboWave/web ci
npm --prefix G:/LimboWave/web run typecheck
npm --prefix G:/LimboWave/web run build -- --emptyOutDir
```

脚本实际以 `G:/LimboWave/web` 为工作目录执行相同命令。`--emptyOutDir` 明确让 Vite 清理其配置的生产输出，避免残留旧哈希文件；不要并行运行前端构建与打包。任何一步非零退出、缺 npm、缺清单/锁文件、无法启动命令，均明确失败且不会进入 PyInstaller。成功后还检查非空 `index.html` 和 JavaScript 文件。输出逐行进入现有打包日志，子进程句柄沿用 GUI 取消回调。

PyInstaller 的 onedir/onefile 均通过 `--add-data` 收集整个静态目录到 `limbowave/web/static`，保留 assets 子目录。页面按包内 `__file__` 相对位置解析，不依赖启动工作目录。静态文件保持 MIME 和 `nosniff`；不存在的 API/资源返回错误，不回退为 `index.html`。当前不是任意路径都回退入口的 SPA 路由方案。

### wheel

`G:/LimboWave/pyproject.toml` 已显式包含被 Git 忽略的生产静态资源：

```toml
[tool.hatch.build.targets.wheel.force-include]
"src/limbowave/web/static" = "limbowave/web/static"
```

单独构建 wheel 不会调用 PyInstaller 打包器：发布流水线/构建 hook 仍须先执行上述 npm 步骤并在资源缺失时失败。实际验收须检查 wheel ZIP 中的入口与哈希资产，并在不含源码树的干净安装环境请求页面、CSS、JS 和 API。源码分发也需要单独决定如何携带前端源码/锁文件或预构建资源。

## 排障

| 现象 | 检查事项 |
| --- | --- |
| 手机连不上 | 主机运行且解锁、监听已开启、地址是实际 LAN IP、同网段可互通；访客 Wi-Fi/AP 隔离、VPN 和主机休眠可能阻断连接。 |
| 启动失败 | 端口被占用、地址不属于主机、证书/密钥不匹配、IP SAN 或有效期错误；修复后重试，不放宽 TLS。 |
| 防火墙阻断 | 只对可信专用网络按需允许选定端口，尽量限制来源网段；不全局关闭防火墙，不配置公网转发。 |
| 无证书开启失败 | 确認桌面已勾选 HTTP 风险确认，证书和私钥均为空；手机配对后还需核验资料库密码。 |
| 证书警告 | 手机根 CA 信任、证书链、实际 IP SAN、两端时间；不要绕过警告。 |
| 401/403 | 服务重启、撤销、超时、来源/Host/CSRF 不匹配；使用面板地址，重新配对，不关闭安全校验。 |
| 409 | 共享执行通道忙或 revision 已变化；刷新状态、保留草稿，不自动重复发送。 |
| 页面/JS 404 或白屏 | 确认生产静态构建已成功且实际包包含入口及引用的 assets；检查 MIME/CSP，不启动 Vite 掩盖缺包。 |
