# OOBE 调试入口

仅在**开发环境**的应用窗口中按 **Ctrl+Shift+O**，会先正常停止后台任务、关闭数据库和日志，再重启应用，并在解锁资料库后强制进入正式的首次使用引导（OOBE）。聊天输入框、设置页和 OOBE 页获得焦点时均可使用。长按不会反复触发重启；若设置页因未保存修改而拒绝关闭，则取消本次重启。

- 仅本次启动强制展示，不修改“是否首次使用”的持久化状态。
- 不清空已有配置、聊天记录或密钥，也不绕过主密码解锁。
- 这是真实引导，不是文案演示。点击「保存并配置模型」即保存端点和密钥，随后进入实际模型配置；明确选择默认聊天模型后才完成引导。只想看界面可以在保存前跳过或退出。
- 正在生成的回复会随正常退出停止；请先处理重要的未发送内容。
- 开发环境要求：非打包进程，且加载的是带 `pyproject.toml` 和 `.git` 标记的 `src/limbowave` 源码仓库（支持 Git worktree）。普通安装包、打包版及只有源码而没有仓库标记的环境均不放行。
- 正式环境不注册快捷键，忽略强制 `--oobe` 参数，重启处理和启动器也会拒绝调试请求；正常的首次使用引导不受影响。开发时可直接运行 `python -m limbowave --oobe`。
- 不会自动重建已有安装包；修改源码后，正在运行的旧进程需先更新/重新启动才能获得新快捷键。

快捷键触发的重启沿用原启动参数（包括日志选项），不会把资料库密码或 API 密钥放到启动参数中。

## 实际模型配置流程（2026-10-08）

1. 填写显示名、地址和密钥，点击「保存并配置模型」。端点和加密密钥在此时保存，不会自动挑选或导入清单中的模型。
2. OOBE 内嵌的 `ActualModelsPage` 与「设置 → 站点端点 → 实际模型」共用实现：支持重新拉取、逐个/全部添加、手动输入模型 ID、流式/思考/工具能力编辑和批量检测。
3. 模型清单不可用时仍保留此页，可重试、手动添加或返回修改端点。手动添加不冒充检测成功，能力未知状态保留。
4. 从已添加的模型中明确选择「默认聊天模型」，点击「使用所选模型」。这一步创建或复用逻辑模型绑定并设置默认值；已有绑定会把当前选择的站点置为首选，不产生重复绑定。
5. 返回修改、完成引导或关闭窗口会取消未发出的检测请求，过期结果不写入配置。网络工作在限流的后台线程池运行，进度和持久化回到 GUI 线程处理。

调试重启仍仅开发环境放行，正式环境的正常首次引导不受影响。文案预览使用模拟清单，不调用服务商或写入用户配置。

验证：OOBE、环境检测/重启、实际模型编辑器、设置页与模型服务相关回归共 **330 项通过**；4 个修改源文件的类型检查以及 7 个 Python 文件的代码规范检查通过。已检查深色/浅色、有模型/清单失败四种布局。测试使用临时资料库和模拟网络，包含真实后台线程与 GUI 线程交接测试；未重启用户应用、请求真实服务商或重新打包。

## 语音与联网介绍正式接入（2026-10-27）

用户验收独立示例后，正式引导顺序为：

**产品欢迎 → 接入服务商 → 保存端点和密钥 → 添加模型并明确选择默认模型 → 配置成功 → 语音设置（可跳过）→ 语音陪伴 → 联网查证 → 开始聊天。**

- 新介绍不在模型配置前出现；只有模型选择落盘成功后，才能沿主路径进入。
- 成功页默认进入语音设置；可保存，也可直接跳过，再进入语音陪伴说明，之后到联网。联网页「开始聊天」才发出完成信号。返回介绍不会重复创建模型或重置默认选择。
- 仅接入已验收的语音与联网两个板块。HIST-02 明确不加入；其他介绍留待后续设计。
- 页面右侧保留清楚标注的**离线交互示例**：语音按住、转写、校对与朗读；联网配置开关、逐次允许/拒绝、摘要与正文证据。示例不会录音、发起网络、播放声音或保存工具授权。
- 语音设置作为成功后的默认下一步按需构造，且可跳过；联网设置仍由「看看联网设置」进入。两者复用已有 VoiceSettingsPage / NetworkSettingsPage 及加密凭据服务。主动点击页内保存才修改配置；浏览、返回或跳过不保存。保存不发起试连或搜索。
- 密码输入框不回显；返回、切页、隐藏、关闭/停止引导时清空尚在控件中的密钥。保存失败留在配置页显示安全错误，仍可跳过。已成功保存的配置不会因返回而丢失。
- Esc 先停止活跃示例或取消模拟询问，再退回上一屏。离开/隐藏/应用失活清理模拟计时器与状态；模拟许可不变成真实授权。
- 内容可滚动，小窗口/大字号可转为单列；继续/返回/可选配置按钮留在页脚，不随长正文消失。
- 搜索接入正在其他会话扩展。OOBE 使用通用提供方说明，真实选项与参数由正式联网设置页负责；不复制服务商字段，也不覆盖后端、密钥或权限改动。

本次测试使用临时资料库、离线示例和假服务，不使用真实密钥或收费接口。没有重启用户正在运行的实例，也未重新打包。深浅色及900×700大字号布局已有定向检查。
